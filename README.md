# SukPaGo
우석대학교 파이썬 창작대회 출품작

석파고(SukPaGo)는 교수님의 한국어 강의를 실시간으로 알아듣고 몽골어·중국어·영어로 번역해 화면 맨 앞에 크게 띄워 주는 프로그램입니다.

## 실행

### 저장소에서 (Python만 있으면 됨)

```
python run.py
```

이 한 줄이 아래 단계를 알아서 합니다. 두 번째 실행부터는 이미 된 단계를 건너뛰고 바로 켜집니다.

1. uv(파이썬 환경 관리 도구)가 없으면 설치
2. 필요한 Python 3.13과 라이브러리 설치
3. 음성 인식·번역 모델 받기(약 0.8GB, SHA256 검증)
4. 빠른 안내 문장 음성 만들기
5. 앱 실행

환경과 모델만 준비하려면 `python run.py setup`을 실행합니다.

### 배포판 (Windows)

GitHub Releases의 `SukPaGo-<버전>-win64.zip`을 받아 압축을 풀고 `SukPaGo.exe`를 실행합니다. 모델이 들어 있어서 따로 받을 것이 없습니다.

## 사용법

- **실시간 번역:** [● 녹음 시작]을 누르고 말하면, 말을 멈출 때마다 문장이 확정되고 켜진 언어로 번역됩니다.
- **빠른 안내 버튼:** "떠들지 마세요" 같은 자주 쓰는 문장을 바로 띄우고 읽어 줍니다.
- **번역 창 띄우기:** 번역문만 크게 보여 주는 창을 엽니다. 프로젝터나 두 번째 모니터에 띄우면 됩니다.
- **용어 고치기:** 자주 틀리게 알아듣는 말을 등록하면 다음부터 자동으로 고쳐서 번역합니다(예: 노트북 에램 → NotebookLM).
- **마이크:** 교수님 가까이에 두는 핀마이크나 USB 마이크를 권장합니다. 녹음 버튼 옆 막대로 소리 크기를 확인할 수 있습니다(초록: 적당, 주황: 작음, 빨강: 너무 큼).

## 번역과 음성

- 번역은 무료 MyMemory API, 음성은 edge-tts를 씁니다. 둘 다 API 키가 필요 없습니다.
- MyMemory는 하루 50,000자 한도가 있습니다. 50분 강의를 3개 언어로 번역하면 약 30,000자를 씁니다.
- 인터넷이 끊기거나 한도를 넘으면 내 컴퓨터의 NLLB-600M 모델로 자동 전환합니다. 이때 번역 품질은 떨어지고 새 문장 음성은 나오지 않습니다.
- 설정 파일(`%APPDATA%\SukPaGo\settings.json`)에서 MyMemory 이메일(`mymemory_email`)을 바꿀 수 있습니다.
